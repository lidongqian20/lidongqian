## 快速开始

### 前置要求
- Git
- Node.js 或 Python（根据项目类型）

### 克隆仓库
```bash
git clone https://github.com/lidongqian20/lidongqian.git
cd lidongqian
```

### 安装依赖
```bash
# 如果是 Node.js 项目
npm install

# 如果是 Python 项目
pip install -r requirements.txt
```
